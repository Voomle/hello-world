# VoomDico User App (React Native)

This is the basic structure for the VoomDico user application.

## Getting Started

- Ensure you have Node.js and npm/yarn installed.
- You will also need a React Native development environment (e.g., Expo CLI or React Native CLI setup for your target platform - iOS/Android).

## Available Scripts

Scripts will be added here as the project develops (e.g., `npm start`, `npm run android`, `npm run ios`).

## Entry Point

The main entry point for the app is `index.js` which registers the main `App` component from `src/App.js`.

## Note on Native Modules
If not using Expo, you might need to run "npx react-native link" for certain packages that require native modules.
